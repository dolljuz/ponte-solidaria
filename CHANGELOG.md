# Histórico de versões

As versões seguem SemVer (`MAJOR.MINOR.PATCH`): mudanças incompatíveis incrementam `MAJOR`, novas funcionalidades compatíveis incrementam `MINOR` e correções compatíveis incrementam `PATCH`. As tags de lançamento usam o prefixo `v`.

## v0.3.0

- Adiciona favoritos de projetos persistidos no navegador.
- Permite filtrar o catálogo para exibir somente projetos favoritos.
- Commit de funcionalidade: `feat: persist project favorites locally`.
- Tag anotada: `v0.3.0` — `Release v0.3.0: locally saved project favorites`.

## v0.2.0

- Adiciona busca textual sem distinção de acentos e filtro por área.
- Exibe contagem de resultados e estado vazio.
- Commit de funcionalidade: `feat: add project search and area filters`.
- Tag anotada: `v0.2.0` — `Release v0.2.0: project search and area filters`.
